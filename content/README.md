# Content

This directory holds the source/data boundary for the localization project.

| Path | Role |
| --- | --- |
| `content/dubbing/` | Canonical editable dialogue and voice source. |
| `content/patches/` | Generated, tracked review artifacts (.dmpatch files). |
| `content/assets/` | Patcher/release assets (icons, etc.). |

- `.dmpatch` files are never edited manually. Rebuild them from source.
- Graphics and font source remain in the Resource Studio workflow.
